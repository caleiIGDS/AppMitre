# Sistema de Horarios - Escuela Técnica Emilio Mitre

Aplicación web interactiva para la gestión y visualización de horarios escolares.

## Propósito
Este sistema permite consultar de manera dinámica:
- **Disponibilidad de aulas.**
- **Horarios de profesores.**
- **Horarios por curso y división.**

## Características
- Calendario semanal visual con detección de superposiciones.
- Búsqueda rápida con autocompletado.
- Exportación de horarios a formato PDF.

## Instalación y Uso
1. Instalar dependencias:
   ```bash
   pip install -r requirements.txt
   ```
2. Ejecutar la aplicación:
   ```bash
   python app.py
   ```
3. Acceder en el navegador a: `http://localhost:5000`
